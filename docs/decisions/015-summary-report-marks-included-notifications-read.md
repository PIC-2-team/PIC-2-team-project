# ADR-015: 요약 리포트에 포함된 알림 읽음 처리

## 상태

승인됨

## 배경

보호자가 요약 리포트를 읽어 미확인 알림 내용을 파악한 뒤에도 원본 알림이 미확인 상태로 남아, 알림함의 상태와 실제 확인 흐름이 어긋날 수 있다.

## 결정

- 요약 생성 시작 시점에 미확인 상태였던 알림 ID를 스냅샷으로 보관한다.
- 요약 생성이 성공하면 스냅샷에 포함된 알림 중 해당 사용자 소유이며 여전히 미확인 상태인 항목만 읽음 처리한다.
- 요약 생성이 실패하거나 대상 알림이 없으면 읽음 상태를 변경하지 않는다.
- 생성 중 새로 도착한 알림은 현재 요약에 포함되지 않으므로 읽음 처리하지 않는다.
- 화면에는 요약 완료 후 포함된 원본 알림이 자동으로 읽음 처리된다고 안내한다.

## 고려한 대안

### 사용자의 개별 확인만 읽음 처리

기존 알림별 확인 동작은 명확하지만, 요약 리포트에서 확인한 내용과 읽음 상태가 달라진다. 요약이 성공적으로 제공된 항목은 확인 완료로 간주한다.

### 생성 요청 시점의 미확인 알림 전체를 일괄 처리

요약 생성 중 새 알림도 함께 읽음 처리될 수 있으므로, 실제 요약에 포함된 ID만 갱신한다.

## 결과와 위험

- 요약이 성공하면 보고된 알림이 사용자의 미확인 목록에서 사라진다.
- 요약 생성에 실패한 경우에는 알림 상태가 보존되어 다시 확인하거나 재시도할 수 있다.
- 동시 요청 등으로 이미 읽음 처리된 항목은 재변경하지 않는다.
