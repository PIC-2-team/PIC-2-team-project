# ADR-011: 슈퍼 어드민 당사자 고유 코드 발급 및 관리 체계

**상태:** 채택

---

## 배경

삶결 플랫폼에서는 발달장애인 당사자의 민감한 개인정보(주민등록번호 등)를 직접 취급하지 않고 안전하게 식별하기 위해 `R-` 접두사와 8자리 영숫자로 구성된 전용 고유 코드(`careRecipientNumber`, 예: `R-A1B2C3D4`)를 사용한다.

기존 시스템에서는 보호자(`GUARDIAN`)가 회원가입 후 대시보드에서 당사자를 직접 등록할 때만 고유 코드가 자동 생성되었다. 그러나 복지관 현장 및 지자체 연계 시나리오에서는 다음과 같은 요구사항이 발생한다:
1. **사전 코드 발급 및 오프라인 배포**: 복지관이나 지자체 지원 사업을 통해 당사자 고유 코드를 먼저 발급받아 명찰/바우처/카드 형태로 전달하고, 보호자가 추후 앱 가입 후 코드를 입력해 연동하는 온보딩 흐름 필요.
2. **슈퍼 어드민의 통합 모니터링 및 관리**: 등록된 전체 당사자 수, 발급된 고유 코드, 보호자 매핑 여부(연결됨/미연결), 소속 기관 연결 여부 등을 슈퍼 어드민이 한눈에 파악하고 관리할 수 있어야 함.

따라서 슈퍼 어드민(`ADMIN`)이 당사자를 사전 등록하고 고유 코드를 발급할 수 있는 기능과, 보호자가 발급된 코드로 당사자를 연결(Claim)할 수 있는 체계를 도입한다.

---

## 결정 사항

### 1. 당사자 고유 코드 체계 유지 및 확장
- **형식**: `R-` + 8자리 대문자 영숫자 (기존 `CareRecipientNumberGenerator`와 100% 호환).
- **유일성 보장**: 생성 시 DB 중복 검사를 거쳐 유일성을 보장한다.

### 2. 슈퍼 어드민 사전 발급 및 관리 API
- `POST /api/admin/care-recipients`:
  - 당사자 기본 정보(이름, 생년월일, 성별, 장애 유형 등)를 입력받아 보호자 매핑(`CareGuardian`) 없이 당사자 엔티티(`CareRecipient`)를 생성하고 고유 코드를 발급한다.
- `GET /api/admin/care-recipients`:
  - 전체 등록된 당사자 목록을 조회하며, 연결된 주 보호자 정보(이름, 이메일) 및 소속 기관 정보를 함께 반환한다. 이름 및 고유 코드 검색(`search` 쿼리 파라미터)을 지원한다.

### 3. 보호자 당사자 코드 연결 (Claim API)
- `POST /api/care-recipients/claim`:
  - 보호자가 발급받은 당사자 고유 코드(`R-XXXXXXXX`)를 입력하면, 해당 당사자를 본인의 당사자로 등록(`CareGuardian`에 `PRIMARY`, `ACTIVE` 생성)한다.
  - 이미 다른 주 보호자가 연결된 경우 409 `CONFLICT` 예외를 발생시킨다.

### 4. 피그마 디자인 시스템 기반 슈퍼 어드민 대시보드 UI
- 피그마 디자인 시스템 토큰(`design-system.css`)과 일관된 카드, 폼, 뱃지 스타일을 적용한다.
- 당사자 고유 코드 신규 발급 폼과 발급 성공 시 코드 복사 기능 제공.
- 당사자 관리 목록에서 검색 기능, 고유 코드 복사, 보호자 매핑 상태 뱃지(`보호자 연결됨` / `미연결 (발급 완료)`), 기관 정보 표시.

## 검토한 대안과 트레이드오프

| 대안 | 장점 | 단점 | 선택 여부 |
|------|------|------|----------|
| **대안 1. 코드만 사전 생성하고 정보는 보호자가 입력** | 어드민이 당사자 정보를 일일이 알 필요 없음 | 당사자 식별을 위한 기본 정보(이름, 생년월일 등)가 없어 코드 분실 시 누구의 코드인지 추적 불가 | 기각 |
| **대안 2. 슈퍼 어드민 생성 시 보호자 계정도 강제 지정** | 보호자가 코드 입력할 필요 없이 자동 매핑 | 오프라인 사전 배포 시 보호자가 아직 가입하지 않은 상태가 많아 사전 발급 불가능 | 기각 |
| **대안 3. 어드민 사전 발급 + 보호자 코드 연동(Claim)** | 보호자 가입 전에도 코드 발급 가능하며, 고유 코드와 당사자 기본 정보가 함께 관리되어 추적성 및 현장 사용성이 우수함 | 보호자에게 코드를 안전하게 전달하는 절차가 필요 | **채택** |
